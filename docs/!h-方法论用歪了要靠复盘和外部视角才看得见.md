# 锚点

[!q-MVP 验证 vs 可得性启发的边界](!q-MVP%20验证%20vs%20可得性启发的边界.md) 原来问：刚学完一个方法论就到处套，怎么区分「为了找它的边界而试用」和「因为最近刚学、所以看什么都像它」。

那篇 2026-06-03 立的时候只有一个案例——写 v2 时连着三章用金字塔，§4 已经觉得「读起来跳」，却归因成「§4 是元章、本来就复杂」，直到 §1 被迫改用矩阵才发现是金字塔有边界。延迟一个章节。

现在案例变成三个，而且指向一个那篇自己没写出来的答案。

# 假设（待验）

一句话：

> **方法论用歪了，自己当场感觉不到。要看见它，只有两条路——跟另一个工具比一次，或者回头看自己这几次都用了什么。**

而且两种「用歪」得用两种不同的办法抓：

| 哪一种用歪 | 当时实际感觉到什么 | 靠什么才看得见 |
|---|---|---|
| 这个工具不适合这个问题 | 用着不对劲：读起来跳 / 强行套用 / 效果勉强 | **外部视角**——跟另一个工具比一次。不比，就分不清是「工具不适配」还是「我用得不好」 |
| 我最近老用这一把（可得性启发） | 什么都没感觉，因为它顺手 | **复盘**——回头看自己这几次都用了什么工具 |

## 为什么必须外接，不能靠自己警觉

上游那篇自己列过一条存疑：「元认知本身可能失效——『我现在是在找边界』这条判断，本身可能就是可得性启发的产物」。本假设把这条从存疑变成前提：**别指望元认知，它就是失效的那一环。**

机制上说得通。可得性启发按 [card-@认知偏差清单](card-@认知偏差清单.md) 的精度映射是「易得证据被赋予过高精度」；而精度这个量，按 [PWPE与非对称决策模型](PWPE与非对称决策模型.md) 感知层那张流程图，本来就是「拿不到、只能靠直觉隐式感觉」的那一半——误差能直接拿到，精度拿不到。所以感觉不到不是你不够警觉，是这个量本身取不到。

这也正是 [!h-livewired 与刻意练习的边界是误差能否自我感知](!h-livewired%20与刻意练习的边界是误差能否自我感知.md) 那条线在方法论上的实例：方法论用歪属于「误差感知不到」那一类，所以必须外接一个高精度信号源。

# 三个案例（证据）

| 案例 | 哪一种用歪 | 延迟 | 怎么看见的 |
|---|---|---|---|
| 写 v2 时连用金字塔到 §4 | 工具不适合 | 1 个章节 | §1 被迫改用矩阵——换了工具才知道 |
| 决策清单「把每个模型钉死在一个正号或负号上」（[tracking-@PKM](tracking-@PKM.md) 2026-07-19 产出③） | 工具不适合：把角度压成了条目 | 0，当场 | 复盘对话里 |
| 行动层模板「没有 tracking 对象就先起模板」（同上 产出④） | 老用这一把：先搭框架 | 0，当场 | 同上 |

# 为什么这条线对 audit 有用

它把「我是不是在过度应用某个模型」变成两个能问出口的问题：

- **这次我拿它跟别的工具比过吗？** 没比过 → 「工具不适配」和「我用得不好」你根本分不了，别急着归因。
- **最近三次我都用了哪个？** 如果是同一个 → 先怀疑它只是顺手，不是它合适。

第二问就是 [card-@认知偏差清单](card-@认知偏差清单.md) 给可得性启发开的那个抵制动作「基准率是多少？」落到这里的样子：我用这个工具的次数，和它真正适用的次数，差多少。

# 待验的预测

1. 凡是没跟第二个工具比过就下的「这工具不适配」或「我用得不好」，回头查会发现归因方向是随手挑的、不是判出来的。
2. **纯自己复盘（不跟人对话）抓不到「老用同一把」。** 这条最要紧——见下面存疑第一条，目前没有独立样本。
3. 一个工具刚学完的头几次应用，延迟应该比学完很久之后更长，因为刚学完时它最顺手。v2 那次是刚读完《金字塔原理》，延迟 1 章；07-19 那两次用的是老工具，延迟 0。方向对得上，但 n=3 太少。
4. 「用着不对劲」的三个信号（读起来跳 / 强行套用 / 效果勉强）应该能罩住大部分「工具不适合」的实例。撞到一个明明不对劲、这三条却都不沾的，说明信号清单不全。

# 存疑（别急着当结论）

- **「复盘」那一半的证据不干净。** 两次延迟 0 都发生在跟 AI 的复盘对话里，里面掺了外部视角——严格说那不是「回头看」起的作用，可能还是「另一个人」起的作用。纯自己复盘行不行，没有样本。**这是最该先补的一格。**
- **两种用歪未必分得开。** v2 那次既是「金字塔不适合 §4」，也是「刚读完所以到处套」，两种成分都在。可能是连续的，不是二选一——和 `!h-livewired` 那条「可能是连续谱、不是二分」的存疑同型。
- **外部视角的成本没算。** 每用一个工具都先拿另一个比一次，就是上游那篇自陈的毛病：让最小可行验证不再最小，违反「跑通前不优化」。什么时候值得比、什么时候直接用，本假设没答。
- **本假设自己就可能是可得性启发的产物。** 同一天先做完 [!h-AI 加速阅读但理解得自己写一遍](!h-AI%20加速阅读但理解得自己写一遍.md)（结论是「靠流程，不靠意志力」），紧接着给这篇得出「靠流程，不靠元认知」——同一个形状的答案连出两次。可能是真同构，也可能是当天手上只有这一把锤子。**下次回看，第一个查这条。**

# 待回看条件

- 下次自己一个人复盘（不跟 AI 对话）时 → 看能不能抓到「老用同一把」。补存疑第一格，最该先做
