# 锚点

Ni-Te-audit 把行动分成「技能提升＝刻意练习」和「习惯维持＝战略性懒惰」两类。但技能提升这一侧内部还有一条没画出来的线：

- 体能训练用 `livewired`（用进废退，反馈靠自我感知——能感到更准 / 更稳 / 不疼，good enough 即可）；
- 工作里的仿真工具用 `刻意练习`（3F，需要资深同事做外部校准，要打到专家级）。

两者同属「调用系统 2、主动制造并消化误差」，凭什么一个自我感知就够、另一个非要外部校准？这条线 Ni-Te-audit 只用两句脚注带过，没说清。

# 假设（待验）

一句话：**livewired 是刻意练习的退化特例——分界线是「预测误差能否被自我感知为高精度信号」。**

- 误差能自我感知（体感即时：更准 / 更稳 / 不疼）→ Feedback 环内置，3F 三步并成一步「用进废退」，自我感知本身就是校准，good enough 够用 ＝ livewired。
- 误差不能自我感知（盲区：系统 1 把噪声当反馈、「看上去很努力」、你以为对了其实错了）→ Feedback 环必须外接一个高精度信号源（专家 / 资深同事）→ 这才是完整的刻意练习。

用 PWPE 的话说：刻意练习的核心是「获得高精度误差反馈」。两者的差别不在要不要反馈，在**高精度反馈从哪来**——体感自带高精度（疼不会骗人），而技能盲区里自我感知是低精度的（会把噪声当信号），所以得外借专家的高精度。

# 为什么这条线对 audit 有用

它给每一个 Te 行动加了一个能判定的问题：**这件事的误差，我自己感知得到吗？**

- 感知得到 → 归 livewired，自我反馈即可，别浪费外部校准的成本（good enough 就收）。
- 感知不到 → 必须上外部校准，否则就是「看上去很努力」（Ni-Te-audit 反例栏原话）。

这把「要不要引入资深同事 / AI / 老师」从拍脑袋变成一个判据。

# 待验的预测（未来 audit 的素材）

拿这条线去扫现有行动，看它分不分得干净：

- **吉他**（作者爱好，自评 Ni-Ti 缺 Te）：音准 / 节奏能自己听出来一部分（livewired 侧），但到演奏级的手型、表现力有盲区、需要老师（刻意练习侧）→ 预测吉他是「跨线」的：低阶靠自我感知，高阶必须外部校准。若属实，说明同一技能会随水平从 livewired 迁移到刻意练习。
- **写作 / 笔记**：逻辑漏洞一部分能重读发现（自我感知），一部分是盲区、要别人（AI / 同频者）顶才看见 → 预测落在刻意练习侧，外部校准省不掉。
- **体能各项**：预测全部稳定落 livewired 侧，正好验证 Ni-Te-audit 脚注 1 的分法。

# 存疑（别急着当结论）

- 「误差能否自我感知」可能是**连续谱**，不是二分——同一件事低阶能感知、高阶感知不到（见吉他）。那「边界」其实随水平移动，不是一次性归类。这是本假设最可能被推翻的地方。
- 还有第二个变量搅进来：**目标高度**（good enough vs 专家级）。也许真正的判据是两维——「误差可感知度 × 目标高度」，而不是单看可感知度。留到 audit 时看能不能并回一维。

# 待回看条件

- 真跑一轮技能 tracking、撞到「我以为练对了其实错了」（自我感知失效）的实例 → 回看假设第一条。
- 吉他或任一技能从「自己练就行」变成「得找老师」时 → 回看「跨线迁移」的预测。
- 攒到 2-3 个行动的分类结果 → 回看「单维还是双维」这条存疑。
