## 背景

在 PWPE与非对称决策模型一文中，分别从感知层、认知层和决策层三个方面对「大脑是如何决策的」进行了解释：大脑通过 PWPE 在决策层给出方向，继而更新先验模型

但是认知觉醒 ≠ 纳入能力圈，只有「经过实践」的东西才等同于能力圈范围之内

实际上，从荣格八维的角度分析，以 Te 为评判标准，可以把 Ni 分为以下几类：

1. 有哪些 Ni 是我值得用 Te 落地而目前尚未落地的 → 我称之为「扩展能力圈的一种可能性」

2. 哪些 Ni 是当前没必要调用 Te 进行落地的 → 我称之为「储备的 Ni」
3. 哪些 Ni 是调用 Te 正在落地的 → 我称之为「正在尝试纳入能力圈」
4. 哪些 Ni 是已经使用 Te 落地的 → 我称之为「能力圈范围之内」

按照这个分类，我们首先需要一套「把先验变成系统1」的方法论，适用对象对应上述的 1 和 3 两点

## 方法论：刻意练习 + 战略性懒惰

刻意练习是人为地制造高精度误差，让神经元重塑 (livewired), 从而持续校准低精度但稳定的先验模型

也就是说，刻意练习的本质是通过调用系统 2 的主动推理（即行动）不断强化系统 1 的过程

战略性懒惰则是通过刻意的设计环境，以自由能最小化为原则，通过 SOP/自动化/阻力最小化等手段，避开调用系统 2, 让正确的选择变成系统 1 的默认选项

二者的对比如下表所示：

|             | 刻意练习                                                     | 战略性懒惰                              |
| ----------- | ------------------------------------------------------------ | --------------------------------------- |
| 底层机制    | 主动制造并消化高精度误差                                     | 用环境把预测误差压到系统 1 可以默认处理 |
| 调用系统 2? | 是                                                           | 否                                      |
| 方法        | Focus: 开启系统 2<br />Feedback: 获得高精度误差反馈<br />Fix: 修正误差，强化系统 1 | SOP<br />自动化<br />阻力最小化         |
| 适用范围    | 技能提升                                                     | 习惯维持                                |
| 反例        | 缺少 Focus → 不想学习 <br />缺少 Feedback → 把噪声当作反馈，只是看上去很努力<br />缺少 Fix → 模型拒绝修正，学习陷入停滞 | 路径依赖<br />思维定势                  |

> 技能提升这一侧内部还有条边界：体能用 livewired（脚注 [^1]，自我感知反馈），工作用完整刻意练习（脚注 [^2]，外部校准）——为什么一个自我感知就够、另一个非要外部校准，展开成可验假设见 [!h-livewired 与刻意练习的边界是误差能否自我感知](!h-livewired%20与刻意练习的边界是误差能否自我感知.md)。
