# 锚点句

当我通过刻意练习积累出**强大的心理表征**，我是否同时在**固化自己的思维方式**——让自己看不到表征之外的世界？

下棋高手能"下一步看三步"——这是心理表征的成果。但同样的心理表征也意味着，他**只能从棋的视角**看人生：他看到一桩商业谈判，本能反应是"对手在试我什么变招"。

心理表征 = 模式识别 = 思维定式？

# 张力

**刻意练习立场**（[book-@刻意练习](book-@刻意练习.md)）：

- 杰出人物的核心区别是心理表征质量
- 心理表征通过反馈和修正不断优化
- 没有心理表征就没有专业能力——你永远是新手

**反方立场**（来自我自己的反思）：

- 心理表征本质是**模式压缩**——把复杂现实压成可识别的少数模式
- 压缩不可避免地**丢失例外**——而例外往往是创新发生的地方
- 专家比新手更难看到"棋局之外的可能"——因为新手没有定式

**两个事实**：
- 没有心理表征 = 永远新手（低能力）
- 心理表征过强 = 模式囚徒（高能力但低适应）

那么真问题：**有什么机制能在保留心理表征的能力红利的同时，避免它的固化代价？**

# 不确定的地方（最重要）

我不确定的判断标准：

- **如何判断我已经被心理表征"囚禁"了**？
  - 自检指标：遇到反例时反应是"这是特例"还是"模型可能错"？
  - 多久没有真正修改过自己的核心模型了？
- **能否在某个专业领域深耕的同时保持开放性**？
  - 这是不是和"既要又要"一样矛盾？
  - 还是有具体方法（如定期跨界 / 主动找反例）？
- **集体智慧是否能解？** 即不在个体身上化解定式，而是通过多人不同表征的对话互相补盲
  - 这又触及了博弈论 / 沟通的范畴

# 候选 hypo（暂无成熟方案）

几个候选方向，但都不充分：

1. **定期跨界打破固化** —— 但跨界本身可能浮于表面，难形成新表征
2. **主动找反例** —— 但反例的"识别"本身依赖现有表征
3. **多源输入对抗** —— 多人 / 多视角对话，但又涉及社交博弈
4. **意识到"我有定式"作为元认知** —— 但意识本身不是行动

这是个**未收敛的问题**，目前没有候选 hypo 强到值得固化。先放在这里发酵。

## 裁决：触发条件严格说没满足

本篇等的是「在自己已有心理表征的领域遭遇模式失效——一个判断错了，但按既有表征『应该对』」。这半年最接近的两次都沾边、都不正中：

- 女友（INTP）批「建造式 PKM 过于看长线、忽略当下」（2026-07-11，已进 [tracking-@PKM](tracking-@PKM.md) 2026-07-30「认知觉醒 ≠ 能力圈」）——是整个取向被外部戳破，不是一个具体判断错了
- [tracking-@PKM](tracking-@PKM.md) 2026-07-19 产出③「决策清单把角度压成条目，这次发生在自己手里」——是自己犯了自己批过 v2 的那个错，更像灯下黑，不是表征固化

所以不硬判它触发。另：本篇 2026-05-04 立，「6 个月没动 + 没新触发就降级」那条要到 2026-11 初才到期。

## 但上面那 4 个候选方向，已经变了 3 个

对应「候选 hypo（暂无成熟方案）」那节——当时给四条的评语都是「不充分」：

| 原候选方向 | 2026-08-16 现状 |
|---|---|
| 1 定期跨界打破固化 | 没动 |
| 2 主动找反例 | **已制度化**：每张 card 的 §5「边界与反例」是固定段落；`docs/_scratch-边界地图-原料汇集.md` 把 5 张卡的 §5 原样汇集；`archive/tracking-@PKM-2026`「主动找 AI 的反例，首先对 AI 持怀疑态度」 |
| 3 多源输入对抗 | **已发生，且库里有现成方法**：女友那次是实例；[book-@思考，快与慢](book-@思考，快与慢.md) §3.3「创造外部视角」给了两个动作——基率思维 +「如果一个外部顾问来看这件事，他会怎么说？」；[card-@认知偏差清单](card-@认知偏差清单.md) §4 也有「引入第三方视角」 |

## 自检指标有了更准的版本

上面「不确定的地方」写的是「遇到反例时反应是『这是特例』还是『模型可能错』」。[card-@精度操控三型](card-@精度操控三型.md) 的「**精度锁死**」说的是同一件事，但接上了机制——「先验精度无穷大，见反证也不更新」，配的自检问是「**学习是否停滞了？**」，并且能对上 [card-@认知偏差清单](card-@认知偏差清单.md) §5 的贝叶斯故障表（锚定 / 确认偏差 → 先验精度过高）。将来改写时用卡片那一版。
